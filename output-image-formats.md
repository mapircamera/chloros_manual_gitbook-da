# Outputbilledformater

### TIFF (16-bit)

16-bit (digitalt pixelværdi 0 - 65535) TIFF (.tif) format.

### TIFF (32-bit, procent %)

32-bit (pixel float 0,0 - 1,0) TIFF (.tif) formatudskrift. Pixelværdier repræsenterer reflektansprocenter, hvor 0,0 = 0 % og 1,0 = 100 %.

### **JPG (8-bit)**

8-bit (digitalt pixelværdi 0 - 255) JPG (.jpg) formatoutput.

### **PNG (8-bit)**

8-bit (digitalt pixelværdi 0 - 255) PNG (.png) format. Tabsfri komprimering, der er velegnet til visning på internettet og visualisering.
